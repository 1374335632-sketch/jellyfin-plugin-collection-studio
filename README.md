# Collection Studio · 合集工坊

Jellyfin 插件：按元数据自动生成合集，支持演员写真封面、源名称替换、改名对照、备份还原。全中文界面。

- 插件 GUID：`c7d1a2b4-9e53-4f18-8a2c-6b3d5e7f9041`
- 插件显示名：`Collection Studio`
- 支持 Jellyfin：**10.9 / 10.10 / 10.11 / 12.4**

---

## 一、在线安装

控制台 → 插件 → 管理存储库 → 添加：

| Jellyfin 版本 | 存储库 URL |
|---|---|
| **12.4** | `https://gh-proxy.com/https://raw.githubusercontent.com/1374335632-sketch/jellyfin-plugin-collection-studio/main/manifest-12.json` |
| 10.10 / 10.11 | `https://gh-proxy.com/https://raw.githubusercontent.com/1374335632-sketch/jellyfin-plugin-collection-studio/main/manifest-10.json` |
| 10.9 | `https://gh-proxy.com/https://raw.githubusercontent.com/1374335632-sketch/jellyfin-plugin-collection-studio/main/manifest-109.json` |

保存后在「目录」页找到 **Collection Studio**，选择要装的版本，点安装，重启 Jellyfin。

### 强制刷新版本列表

CDN 有 60 秒缓存，刷新后仍看不到新版本时，在 URL 末尾加时间戳：

```
...manifest-12.json?v=1794046000
```

`?v=` 后任意数字即可。或用插件自带的清单代理（需已装 1.8 以上）：

```
http://你的服务器:8096/CollectionStudio/Manifest
```

它每次请求自动带时间戳绕过缓存，且走服务器本地网络，不受 raw 域名被墙影响。

| 4.7.0.x | 修搜索失效、两开关独立判断 | 可用 |

| 4.4.0.x | 媒体库文件清单表（四列排序） | 可用 |
| 4.3.0.x | 改名/刮削拆分为独立操作 | 可用 |
| 4.2.0.x | 修复 400 错误、错误原文可见 | 可用 |
| 4.1.0.x | 修复全表格文字看不清 | 可用 |
| 4.0.0.x | 重命名复原、批量删合集、表头排序、一键加源、任务定时 | 可用 |
| 3.1.0.x | 源名称替换只看影片名 | 可用 |
| 3.0.0.x | 首次引入源名称替换规则 | 可用 |
| 2.1.0.x | **不含源名称替换**，其余与 3.x 相当 | 精简 |
| 1.x | 早期版本：注入页方案，按钮在 12.4 上不可用 | 仅存档 |

### 关键差异点

**是否含源名称替换（刮削前改名）**

- 含：3.0.0.x 及以上全部版本
- 不含：2.1.0.x（若你只需要合集与改名对照，不需要改文件名，这个版本更精简）

**界面能否交互（12.4 专有关键问题）**

Jellyfin 12.4 把插件配置页当「视图注入」，注入内容中的 `<script>` 不执行，导致早期版本按钮全部失效。

| 版本范围 | 方案 | 12.4 可用性 |
|---|---|---|
| 1.x ~ 1.6.x | 注入页 + 内联脚本 | **不可用**（按钮无反应） |
| 1.7.0.x ~ 至今 | **iframe 内嵌完整页面** | **可用** |

所以 12.4 上最小可用版本是 **1.7.0.2**，生产使用建议直接装 5.1.0.2。

**改名与刮削的耦合关系**

| 版本 | 行为 |
|---|---|
| 3.x | 强制「重命名 → 写入名称 → 触发刮削」一条链 |
| 4.3.0.x+ | 拆成「只改名」「只刮削」「两者依次」三个独立按钮 |

**匹配基准的语义变化**

| 版本 | 源名称取自 |
|---|---|
| 3.0 ~ 4.2 | Jellyfin 里的影片显示名 |
| **4.3.0.x+** | **磁盘上的实际文件名**（不含扩展名） |

4.3 起：读磁盘文件名 → 按规则计算 → 写入 Jellyfin 名称 / 改磁盘文件名。两个开关都以磁盘文件名为基准。

## 三、功能说明

### 1. 分类规则（合集生成）

按元数据自动生成合集，每个值一个合集，合集名可用 `{value}` 占位符。

支持的分组模式：

| 模式 | 说明 |
|---|---|
| 按演员 / 导演 | 每个演员/导演一个合集 |
| 按厂商（片商） | 每个片商一个合集 |
| 按类型 / 标签 | 每个类型一个合集 |
| 按年份 | 每年一个合集 |
| 按分级 | 每个官方分级一个合集 |
| 高级自定义 | 多字段多条件组合，合集名自定义 |

**参与分类的媒体库**：每条规则可指定只处理哪些媒体库，不选等于全部。

**排序**：可选发行日期、添加时间、名称、评分等字段，升序/降序。

**封面来源**：取第一个影片封面，或从 MetaTube / 自定义源抓取写真。

### 2. 上市规则诊断

规则执行结果为 0 时，点「诊断」会逐层显示：

```
索引总条目        13
按媒体库过滤后    13
再按条件过滤后    13
带演员信息的条目   9
最终分组数         0   ← 这里为 0 说明缺分组字段
```

并给出中文结论：索引为空 / 媒体库错配 / 缺失分组字段 / 条件过严。

### 3. 源名称替换（刮削前改名）

**规则格式**：`模式:替换文本`

- 冒号前是匹配模式，冒号后是替换内容，**留空即删除**
- 以 `*` 开头表示「任意前缀」通配
- 其余按正则处理
- 全角冒号 `：` 自动识别

**常用写法**

| 需求 | 规则 | 结果 |
|---|---|---|
| 删除 @ 及之前 | `*@:` | `1561684@vvvv-66` → `vvvv-66` |
| 删除指定前缀 | `*hhd800@:` | `hhd800@abc-001` → `abc-001` |
| **只保留括号里品番** | `\((6666-[0-9-]+)\):` | `(MAXING)(6666-1105)` → `6666-1105` |
| 指定取第 2 个捕获组 | `\(([A-Z]+)\)\(([0-9-]+)\):$2` | 同上 |
| 删掉方括号前缀 | `.*\[Group\]:` | `[Group] abc-123` → ` abc-123` |

**提取语义（4.5 起）**：正则里有捕获组、替换文本留空时，自动取第一个非空捕获组，无需写字面替换文本。

**执行顺序（固定）**

```
1. 重命名磁盘文件（可选，需勾选）
2. 写入 Jellyfin 名称（可选，需勾选）
3. 触发元数据刷新（刮削）
```

4.3 起可分别执行：**只改名** / **只刮削**。

**三个开关**

| 开关 | 匹配来源 | 写入目标 |
|---|---|---|
| 启用先重命名再刮削 | — | 总开关 |
| 同时改写 Jellyfin 名称 | 磁盘文件名 | Jellyfin 影片名称 |
| 同时重命名磁盘文件 | 磁盘文件名 | 磁盘上的文件名 |

### 4. 重命名复原

每次执行改名都会记录 `原名 / 新名 / 原路径 / 新路径`，按批次分组。

「备份与还原」页 → 「重命名复原」卡片：

- 列出每个批次：批次号、条数、时间
- 「查看明细」看逐条原样
- 「复原此批」把磁盘文件搬回原名、Jellyfin 名称改回原名

媒体文件只移动不删除。

### 5. 改名对照表

- 路径 / 原始名称 / Jellyfin 名称 / 类型 / 年份 / 所属合集
- 每页 50 / 100 / 200 条
- 筛选框按 Jellyfin 名称过滤（停止输入 350ms 自动筛）
- **表头点击排序**（升序 / 降序切换）
- 导出当前结果到 Excel（可存服务器或直接下载）

### 6. 媒体库文件清单（排查命名）

设置页顶部的表，实时从磁盘读取：

| 列 | 排序 |
|---|---|
| 磁盘路径 | 可点 |
| 磁盘影片名称 | 可点 |
| 修改日期 | 可点 |
| 大小 | 可点 |
| Jellyfin 名称 | — |
| 状态 | 自动标出「名称不一致」 |

数据不走索引缓存，用 `FileInfo` 读取真实修改时间与字节数。

### 7. 合集管理

- 封面、合集名、所属规则、影片数、更新时间
- **批量删除**：勾选多个 → 删除选中（**只删合集条目，绝不删媒体文件**）
- **清理失效记录**：Jellyfin 里已不存在的合集自动从表格移除
- 进页自动刷新，避免手动删除后表格残留
- 改封面 / 查看成员影片 / 删除单个

### 8. 备份与还原

- 名称格式：`Collection Studio_backup_yyyyMMdd_HHmmss_fff`（毫秒精度）
- 执行规则前自动备份、删除前自动备份、手动备份
- 按时间段选择 → 预览 → 确认还原
- 还原前自动再备份一次

### 9. 定时任务

总览页可设置扫描任务的**每日启动时间**（默认 03:30），保存即生效，无需重启。会保留原有的「启动时触发」。

### 10. 写权限检查（5.0 起）

对媒体库实际目录做**真实写入测试**（创建临时文件再删除），并读取容器内 `/proc/mounts`：

| 列 | 含义 |
|---|---|
| 所在挂载点 | 该目录实际落在哪个挂载点 |
| 只读 | 该挂载点的真实只读状态 |
| 可写 | 写入测试结果 |
| 结论 | 只读挂载 / 无写权限 / 目录不存在 + 处理命令 |

## 四、安装后必做的配置

### 1. MetaTube 地址

设置页 → MetaTube 地址填 `http://你的MetaTube地址:8080`，点「测试连接」确认可达。

**注意**：地址必须是 **Jellyfin 服务器所在网络**能访问的，不是浏览器本机能访问的。

### 2. 元数据不要写到媒体文件夹

控制台 → 媒体库 → 编辑：

- **取消勾选**「将图片保存到媒体文件夹」
- **元数据路径**填本地可写目录，如 `/config/metadata`
- 「元数据保存器」里若不需要 NFO 也取消勾选

这样刮削产生的图片和元数据存到 Jellyfin 配置目录，不落到媒体共享上。

### 3. 磁盘改名需要挂载可写

若媒体在 CIFS/SMB 网络共享上，注意两点：

**嵌套挂载不会自动传进容器**

`-v /:/media` 只挂载 `/` 这一层，内层的网络挂载点（如 `/yingshi`）不会被带入，容器内该路径落在只读层。需要显式再挂一行：

```yaml
volumes:
  - /:/media
  - /yingshi:/media/yingshi:rw    # 新增，显式挂载
```

**CIFS 挂载要加 `nobrl`**

```
nobrl,username=...,password=...,rw,vers=3.1.1,iocharset=utf8,soft
```

缺 `nobrl` 时 `File.Move` 会因字节范围锁失败。

### 4. 媒体转码与缓存目录

控制台 → 播放 → 转码 → 转码路径填本地可写目录（如 `/cache/transcodes`）。

容器部署时建议把 `cache_path` 也指到大容量分区：

```sh
uci set jellyfin.@jellyfin[0].cache_path='/mnt/sdb1/jellyfin-cache'
uci commit jellyfin
```

## 五、典型使用流程

### 场景 A：按演员生成合集并自动写封面

1. 总览 → 立即扫描，等索引跑完
2. 分类规则 → 新建规则
   - 分类模式：按演员
   - 参与分类的媒体库：勾选「电影」
   - 合集名模板：`{value} 合集`
   - 封面来源：MetaTube 演员写真
3. 点「预演」确认分组数和影片数
4. 点「执行」生成合集

### 场景 B：先改名再刮削，保证 MetaTube 匹配准确

1. 设置页 → 源名称替换
2. 规则填 `\((6666-[0-9-]+)\):`
3. 试算输入 `(MAXING)(6666-1105)` → 确认得到 `6666-1105`
4. 勾选「同时改写 Jellyfin 名称」，**先不勾**「同时重命名磁盘文件」
5. 点「预演改名」看清单
6. 点「只改名」→ Jellyfin 名称改好，磁盘文件不动
7. 点「只刮削」→ MetaTube 按新名称重新匹配

### 场景 C：排查哪些文件名不规范

设置页 → 媒体库文件清单：

1. 媒体库选「电影」
2. 按「大小」排序，看是否有异常小的文件（可能残片）
3. 按「修改日期」排序，看批量导入的时间段
4. 看「状态」列的「名称不一致」标记，逐条核对

## 六、故障排查

### 按钮点了没反应

12.4 上见 1.7 之前版本的已知问题（注入页不执行脚本）。升级到 **1.7.0.2 以上**。

升级后仍无反应，打开 F12 控制台看：

- `[Collection Studio] 初始化失败：` 后面的错误
- 或输入 `window.__csInitError`

### 规则执行结果为 0

点规则行的「诊断」，看哪一层归零：

| 归零层 | 原因 | 处理 |
|---|---|---|
| 索引总条目 | 还没扫描 | 总览点「立即扫描」 |
| 按媒体库过滤后 | 规则选的库 id 与索引不符（重建库后 id 会变） | 编辑规则重新勾选 |
| 带演员信息的条目 | 影片缺 actor 元数据 | 补齐元数据，或改用厂商/类型/年份分组 |
| 再按条件过滤后 | 高级条件太严 | 放宽条件 |

### 磁盘文件改不了

点「检查写权限」，按结论处理：

| 结论 | 处理 |
|---|---|
| 只读挂载 | 检查容器 volume 是否带 `:ro`；网络盘需显式挂载 |
| 无写权限 | `chown -R 1000:1000 <目录>` |
| 目录不存在 | 媒体路径变了，更新媒体库路径 |

CIFS 共享还需在挂载参数加 `nobrl`。

### 刮削报「无法构造 MetadataRefreshOptions」

1.4.9 之前的 bug（命名空间写错 + 缺 `IDirectoryService`）。升级到 **4.8.0.2 以上**。

### 看不到新版本

CDN 60 秒缓存。清单 URL 加 `?v=时间戳`，或直接删掉存储库重新添加。

## 七、手动安装

从 `dist/` 下载对应架构的 zip：

| 文件 | Jellyfin 版本 |
|---|---|
| `Jellyfin.Plugin.CollectionStudio-5.1.0.0-net8.0.zip` | 10.9 |
| `Jellyfin.Plugin.CollectionStudio-5.1.0.1-net9.0.zip` | 10.10 / 10.11 |
| `Jellyfin.Plugin.CollectionStudio-5.1.0.2-net10.0.zip` | 12.4 |

解压到 `<data>/plugins/Collection Studio_5.1.0.2/`，确保目录内有：

```
Jellyfin.Plugin.CollectionStudio.dll
LiteDB.dll
meta.json
```

重启 Jellyfin。

**注意**：手动安装的目录名建议与版本号一致，且必须包含 `meta.json`——缺了它 Jellyfin 不会加载插件，也无法在控制台禁用它。

## 十、版本边界与已知限制

- **12.4 注入页限制**：控制台以视图注入配置页，注入内容不执行脚本。本插件用 iframe 内嵌完整页面绕开（1.7 起）。
- **磁盘改名需挂载可写**：只读挂载、CIFS 文件锁都会导致 `File.Move` 失败。插件会返回具体原因并提供检查工具。
- **元数据落盘位置**由 Jellyfin 自身设置决定，插件不覆盖。
- **MetaTube 可达性**以 Jellyfin 服务器网络为准，不是浏览器所在机器。
