源名称替换（刮削前执行）

规则格式：模式:替换文本。冒号前是匹配模式（以 * 开头表示「任意前缀」，其余按正则）， 冒号后是替换内容，留空即删除。例：源名称 1561684@vvvv-66，规则 *@: 得到 vvvv-66。 执行顺序固定为：重命名 → 写入名称 → 触发刮削。
